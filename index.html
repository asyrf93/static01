GitHub Pages starter

Hello. This is your website.

Everything here is one file. Change the words, put it on GitHub, and turn on Pages. No install and no build step.

Publish it

  1. 01

    Create a repository

    On GitHub, make a new public repo. Name it yourusername.github.io for a personal site, or anything else for a project site.

  2. 02

    Add this file

    Upload index.html to the root of the repo, or push it with git. Keep that exact filename.

  3. 03

    Turn on Pages

    Repo → Settings → Pages. Deploy from a branch. Branch main, folder / (root), then save.
